### 1. 主页面

### 2. 驾驶舱主组件
**`frontend/components/cockpit/ContentCockpit.tsx`**
- 双屏布局实现
  - 左侧：策略配置面板（固定宽度 384px）
  - 右侧：预览/对比/批量视图（自适应）
- 状态管理
  - generationState: 生成状态（idle/running/paused/completed/error）
  - strategyConfig: 策略配置
  - activeView: 当前视图（preview/comparison/batch）
- 控制按钮
  - 开始生成
  - 暂停/继续
  - 重置
- Tab 切换
  - 实时预览
  - 内容对比
  - 批量生成

### 3. 策略配置面板
**`frontend/components/cockpit/StrategyPanel.tsx`**
- 基础配置
  - 主题输入（必填）
  - 平台选择（小红书/抖音/B站/微博/微信）
  - 目标指标（互动率/完播率/转化率）
  - 目标受众（可选）
  - 内容风格（专业/轻松/情感/教育/故事）
  - 批量大小（1-16，滑块控制）
- 高级设置（折叠）
  - 探索率（0-100%）
  - 温度参数（0-2.0）
  - 启用 RAG 检索
  - 启用自动重试
- 策略摘要
  - 实时显示当前配置概览

### 4. 实时预览面板

  - 平均评分
  - 通过率
  - 预测互动
- 内容网格

  - 前3名显示排名徽章（金/银/铜）
  - 使用 ContentCard 组件展示
  - 快速操作按钮（编辑/复制/导出）

- 状态消息

## 技术亮点

### 1. 双屏布局
- **固定+自适应**: 左侧固定宽度，右侧自适应
- **响应式设计**: 支持不同屏幕尺寸
- **独立滚动**: 左右面板独立滚动
- **清晰分隔**: 边框分隔，视觉清晰

### 2. 状态管理
- **集中管理**: 主组件统一管理状态
- **单向数据流**: 父组件 → 子组件
- **回调更新**: 子组件通过回调更新父状态
- **类型安全**: TypeScript 类型定义

### 3. 实时反馈
- **进度条**: 实时显示生成进度
- **步骤指示**: 清晰展示当前步骤
- **状态消息**: 及时反馈错误和完成
- **加载动画**: 旋转图标和进度条

### 4. 交互体验
- **禁用状态**: 生成中禁用配置修改
- **快速操作**: 内容卡片快速操作按钮
- **批量选择**: 最多选择4个内容对比
- **拖拽排序**: （待实现）任务队列拖拽

### 5. 数据可视化
- **统计卡片**: 关键指标一目了然
- **条形图**: 指标对比直观清晰
- **进度条**: 任务进度实时更新
- **排名徽章**: 前3名内容高亮显示

### 6. 批量处理
- **队列管理**: 任务队列自动执行
- **并发控制**: 顺序执行，避免过载
- **错误处理**: 单个任务失败不影响其他
- **批量导出**: 一键导出所有结果

## 用户流程

### 单次生成流程
```
1. 配置策略
   ├─ 输入主题
   ├─ 选择平台
   ├─ 设置目标
   └─ 调整参数

2. 开始生成
   ├─ 点击"开始生成"
   ├─ 显示进度条
   ├─ 步骤指示器更新
   └─ 实时显示内容

3. 查看结果
   ├─ 统计卡片
   ├─ 内容网格
   ├─ 快速操作
   └─ 导出内容
```

### 内容对比流程
```
1. 切换到对比视图
   └─ 点击"内容对比" Tab

2. 选择内容
   ├─ 点击内容卡片
   ├─ 最多选择4个
   └─ 选中状态高亮

3. 查看对比
   ├─ 指标对比图
   ├─ 内容并排展示
   └─ 策略动作对比
```

### 批量生成流程
```
1. 切换到批量视图
   └─ 点击"批量生成" Tab

2. 添加任务
   ├─ 输入多个主题
   ├─ 每行一个
   └─ 添加到队列

3. 开始批量生成
   ├─ 点击"开始批量生成"
   ├─ 任务顺序执行
   ├─ 实时更新状态
   └─ 显示进度

4. 导出结果
   ├─ 查看统计
   ├─ 导出全部
   └─ 清除已完成
```
