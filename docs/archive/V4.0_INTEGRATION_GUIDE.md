## 📦 安装与配置

### 1. 数据库迁移

运行 v4.0 数据库迁移脚本：

```bash
cd backend
alembic upgrade v4_0_growth_brain
```

这将创建以下新表：
- `discovered_topics` - 发现的话题
- `content_schedules` - 内容排程
- `daily_plans` - 每日计划
- `generated_covers` - 生成的封面
- `cover_ab_tests` - 封面 A/B 测试
- `cover_features` - 封面特征
- `unified_content_records` - 统一内容记录
- `platform_adaptations` - 平台适配
- `cross_platform_performances` - 跨平台表现
- `causal_graphs` - 因果图
- `causal_effects` - 因果效应
- `counterfactual_scenarios` - 反事实场景

### 2. 配置环境变量

在 `.env` 文件中添加：

```bash
# 封面生成器 API
STABLE_DIFFUSION_API_KEY=your_sd_api_key
STABLE_DIFFUSION_API_URL=https://api.stability.ai/v1
OPENAI_API_KEY=your_openai_api_key  # for DALL·E
MIDJOURNEY_API_KEY=your_mj_api_key

# 平台账号配置
XHS_ACCOUNT_COOKIE=your_xhs_cookie
DOUYIN_ACCOUNT_COOKIE=your_douyin_cookie
BILIBILI_ACCOUNT_COOKIE=your_bilibili_cookie
```

### 3. 启动服务

```bash
# 启动 FastAPI 服务
uvicorn app.api:app --reload --port 8000

# 启动 Celery Worker
celery -A app.tasks.celery_config worker --loglevel=info

# 启动 Celery Beat（定时任务）
celery -A app.tasks.celery_config beat --loglevel=info
```

## 🎯 使用指南

### 1. 自动化账号运营

#### 1.1 发现热点话题

```python
import requests

# 发现热点话题
response = requests.post('http://localhost:8000/api/v4/account/discover-topics', json={
    "sources": ["xhs_trending", "weibo_trending", "douyin_trending"],
    "limit": 20
})

topics = response.json()['topics']
print(f"发现 {len(topics)} 个热点话题")
```

#### 1.2 创建每日计划

```python
# 为账号创建每日计划
response = requests.post('http://localhost:8000/api/v4/account/daily-plan', json={
    "account_id": "account_001",
    "plan_date": "2026-02-13"
})

plan = response.json()['plan']
print(f"计划ID: {plan['plan_id']}")
print(f"选中话题: {plan['selected_topics']}")
print(f"排程: {plan['schedules']}")
```

#### 1.3 监控内容表现

```python
# 监控已发布内容的前 1 小时表现
response = requests.post('http://localhost:8000/api/v4/account/monitor/schedule_123', json={
    "time_window_minutes": 60
})

performance = response.json()['performance']
print(f"浏览数: {performance['views']}")
print(f"互动率: {performance['engagement_rate']}")
```

#### 1.4 定时任务

系统会自动执行以下定时任务：
- **每天 6:00**: 发现热点话题
- **每天 7:00**: 创建每日计划
- **每小时**: 监控最近发布的内容

### 2. 多模态封面引擎

#### 2.1 生成封面候选

```python
# 生成封面候选
response = requests.post('http://localhost:8000/api/v4/cover/generate', json={
    "title": "冬季护肤攻略",
    "text": "分享我的冬季护肤心得...",
    "style": "realistic",
    "generators": ["stable_diffusion", "dalle"],
    "candidate_count": 5
})

candidates = response.json()['candidates']
print(f"生成 {len(candidates)} 个封面候选")

for c in candidates:
    print(f"封面ID: {c['cover_id']}, 预测CTR: {c['predicted_ctr']:.3f}")
```

#### 2.2 运行 A/B 测试

```python
# 选择 Top 3 候选进行 A/B 测试
top_3_ids = [c['cover_id'] for c in candidates[:3]]

response = requests.post('http://localhost:8000/api/v4/cover/ab-test', json={
    "generation_id": "gen_123",
    "cover_ids": top_3_ids,
    "traffic_split": {
        top_3_ids[0]: 0.33,
        top_3_ids[1]: 0.33,
        top_3_ids[2]: 0.34
    }
})

test_id = response.json()['test_id']
print(f"A/B 测试ID: {test_id}")
```

#### 2.3 获取测试结果

```python
# 1 小时后获取测试结果
response = requests.get(f'http://localhost:8000/api/v4/cover/ab-test/{test_id}')

result = response.json()
print(f"胜出封面: {result['winner_cover_id']}")
print(f"胜出CTR: {result['winner_ctr']:.3f}")
print(f"置信度: {result['confidence']:.2f}")
```

#### 2.4 优化封面风格

```python
# 基于历史数据优化封面风格
response = requests.get('http://localhost:8000/api/v4/cover/optimize-style/account_001?historical_days=30')

recommended_style = response.json()['recommended_style']
print(f"推荐风格: {recommended_style}")
```

#### 2.5 定时任务

系统会自动执行以下定时任务：
- **每小时**: 分析 A/B 测试结果
- **每周日 2:00**: 优化封面风格

### 4. 因果推断引擎

#### 4.1 创建因果图

```python
# 创建因果图
response = requests.post('http://localhost:8000/api/v4/causal/graph', json={
    "graph_name": "content_viral_graph",
    "nodes": [
        {"name": "hook_type", "node_type": "treatment"},
        {"name": "cover_color", "node_type": "treatment"},
        {"name": "publish_time", "node_type": "treatment"},
        {"name": "topic_heat", "node_type": "confounder"},
        {"name": "engagement_rate", "node_type": "outcome"},
        {"name": "viral_score", "node_type": "outcome"}
    ],
    "edges": [
        {"from_node": "hook_type", "to_node": "engagement_rate"},
        {"from_node": "cover_color", "to_node": "engagement_rate"},
        {"from_node": "publish_time", "to_node": "engagement_rate"},
        {"from_node": "topic_heat", "to_node": "hook_type"},
        {"from_node": "topic_heat", "to_node": "engagement_rate"},
        {"from_node": "engagement_rate", "to_node": "viral_score"}
    ]
})

graph_id = response.json()['graph_id']
print(f"因果图ID: {graph_id}")
```

#### 4.2 估计因果效应

```python
# 估计 Hook 类型对互动率的因果效应
response = requests.post('http://localhost:8000/api/v4/causal/effect', json={
    "treatment": "hook_type",
    "outcome": "engagement_rate",
    "common_causes": ["topic_heat", "author_followers"],
    "method": "propensity_score"
})

effect = response.json()
print(f"因果效应: {effect['effect_size']:.2%}")
print(f"置信区间: [{effect['confidence_interval'][0]:.2%}, {effect['confidence_interval'][1]:.2%}]")
print(f"p值: {effect['p_value']:.4f}")
print(f"显著性: {'是' if effect['is_significant'] else '否'}")
```

#### 4.3 反事实推理

```python
# 反事实推理："如果当时用了疑问句 Hook，会怎样？"
response = requests.post('http://localhost:8000/api/v4/causal/counterfactual', json={
    "scenario_name": "question_hook_scenario",
    "actual_treatment": {"hook_type": "statement"},
    "counterfactual_treatment": {"hook_type": "question"},
    "outcome": "engagement_rate"
})

result = response.json()
print(f"实际结果: {result['actual_outcome']:.2%}")
print(f"反事实结果: {result['counterfactual_outcome']:.2%}")
print(f"处理效应: {result['treatment_effect']:.2%}")
print(f"解释: {result['interpretation']}")
```

#### 4.4 发现因果关系

```python
# 自动发现因果关系
response = requests.get('http://localhost:8000/api/v4/causal/discover', params={
    "variables": ["hook_type", "cover_color", "publish_time", "engagement_rate", "viral_score"],
    "time_window_days": 30
})

relationships = response.json()['relationships']
print(f"发现 {len(relationships)} 个因果关系")

for rel in relationships:
    print(f"{rel['from_node']} → {rel['to_node']} (强度: {rel['strength']:.2f})")
```

#### 4.5 定时任务

系统会自动执行以下定时任务：
- **每周一 4:00**: 发现因果关系

## 🔄 完整工作流示例

### 端到端自动化流程

```python
import requests
from datetime import date

# 1. 发现热点话题
topics_response = requests.post('http://localhost:8000/api/v4/account/discover-topics', json={
    "sources": ["xhs_trending"],
    "limit": 10
})
topics = topics_response.json()['topics']
print(f"✅ 发现 {len(topics)} 个热点话题")

# 2. 创建每日计划
plan_response = requests.post('http://localhost:8000/api/v4/account/daily-plan', json={
    "account_id": "account_001",
    "plan_date": date.today().isoformat()
})
plan = plan_response.json()['plan']
print(f"✅ 创建每日计划: {plan['plan_id']}")

# 3. 生成封面
cover_response = requests.post('http://localhost:8000/api/v4/cover/generate', json={
    "title": plan['selected_topics'][0]['topic_name'],
    "text": "...",
    "style": "realistic",
    "generators": ["stable_diffusion", "dalle"]
})
candidates = cover_response.json()['candidates']
print(f"✅ 生成 {len(candidates)} 个封面候选")

# 4. 运行 A/B 测试
test_response = requests.post('http://localhost:8000/api/v4/cover/ab-test', json={
    "generation_id": "gen_123",
    "cover_ids": [c['cover_id'] for c in candidates[:3]]
})
test_id = test_response.json()['test_id']
print(f"✅ 启动 A/B 测试: {test_id}")

# 5. 创建统一内容
content_response = requests.post('http://localhost:8000/api/v4/platform/content', json={
    "title": plan['selected_topics'][0]['topic_name'],
    "body": "...",
    "hook": "...",
    "call_to_action": "...",
    "content_type": "text",
    "cover_image_path": candidates[0]['image_path'],
    "topic": plan['selected_topics'][0]['topic_name'],
    "tags": ["护肤", "冬季"]
})
content_id = content_response.json()['content_id']
print(f"✅ 创建统一内容: {content_id}")

# 6. 发布到多平台
publish_response = requests.post('http://localhost:8000/api/v4/platform/publish', json={
    "content_id": content_id,
    "platforms": ["xiaohongshu", "douyin", "bilibili"],
    "account_id": "account_001"
})
results = publish_response.json()['results']
print(f"✅ 发布到 {len(results)} 个平台")

# 7. 因果分析
effect_response = requests.post('http://localhost:8000/api/v4/causal/effect', json={
    "treatment": "hook_type",
    "outcome": "engagement_rate",
    "common_causes": ["topic_heat"],
    "method": "propensity_score"
})
effect = effect_response.json()
print(f"✅ 因果效应: {effect['effect_size']:.2%}")

print("\n🎉 完整工作流执行完成！")
```

## 🔧 故障排查

### 常见问题

1. **封面生成失败**
   - 检查 API 密钥是否配置正确
   - 检查 API 配额是否用完
   - 查看日志: `tail -f logs/cover_engine.log`

2. **平台发布失败**
   - 检查账号 Cookie 是否过期
   - 检查平台限流状态
   - 查看日志: `tail -f logs/platform_engine.log`

3. **因果推断错误**
   - 检查数据量是否足够（建议 > 1000 样本）
   - 检查变量是否存在
   - 查看日志: `tail -f logs/causal_engine.log`
