# 🚀 Viral Flywheel - 项目概览

## 📋 项目信息

**项目名称**: Viral Flywheel (爆款飞轮)
**当前版本**: v4.0.0 (Growth Brain)
**项目状态**: ✅ 生产就绪
**累计代码**: ~30,920 行
**开发周期**: v2.6 → v4.0
**最后更新**: 2026-02-12

---

## 🎯 项目愿景

**从"内容引擎"进化为"增长大脑"**

Viral Flywheel 是一个 AI 驱动的爆款内容自动化系统，通过数据闭环、强化学习和因果推断，实现从内容生成到增长决策的完整自动化。

## 🛠️ 技术栈

### 后端
- **语言**: Python 3.9+
- **框架**: FastAPI
- **数据库**: PostgreSQL 13+
- **缓存**: Redis 6+
- **任务队列**: Celery 5+
- **机器学习**: LightGBM, scikit-learn
- **因果推断**: DoWhy, EconML (概念)

### 前端
- **框架**: Next.js 14
- **语言**: TypeScript
- **UI**: React 18, Tailwind CSS
- **状态管理**: React Hooks
- **实时通信**: WebSocket

### 基础设施
- **容器化**: Docker
- **编排**: Docker Compose
- **监控**: Prometheus + Grafana (规划)
- **日志**: ELK Stack (规划)
