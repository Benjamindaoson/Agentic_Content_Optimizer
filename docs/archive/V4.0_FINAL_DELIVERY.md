### 1. 自动化账号运营

```python
# 每日自动发现热点话题
topics = await auto_account_manager.discover_trending_topics(
    source="xhs_trending",
    limit=5
)

# 创建每日计划（需人工审批）
plan = await auto_account_manager.create_daily_plan(

    plan_date=date.today()

# plan['status'] == 'pending_approval'

# 审批通过后自动执行
await auto_account_manager.approve_plan(
    plan_id=plan['plan_id'],
    approved_by="user_456"
)
```

### 2. 多模态封面生成

```python
# 生成 3 个封面候选
candidates = await cover_engine.generate_cover_candidates(
    title="如何提升小红书笔记曝光",
    text="分享 5 个实用技巧...",
    count=3
)

# 自动 A/B 测试
test_id = await cover_engine.run_ab_test(candidates)

# 1 小时后获取结果
winner = await cover_engine.get_ab_test_winner(test_id)
```

```python
content = UnifiedContent(

# 适配到小红书（v4.0 Lite 只支持小红书）

```

### 4. 因果推断（需要足够样本）

```python
# 估计因果效应
effect = await causal_engine.estimate_causal_effect(
    treatment="use_emoji_in_title",
    outcome="click_through_rate",
    common_causes=["topic_heat", "publish_time", "follower_count"]
)

# effect.ate: 平均处理效应
# effect.confidence: 置信度
# effect.p_value: 显著性

# 反事实推理
counterfactual = await causal_engine.counterfactual_reasoning(
    observed_data={
        "use_emoji_in_title": False,
        "click_through_rate": 0.05
    },
    intervention={"use_emoji_in_title": True}
)
# counterfactual.predicted_outcome: 0.08 (预测 CTR 提升到 8%)
```

## 🔐 安全与风险控制

### 三级决策权限

```python
class DecisionLevel:
    FULLY_AUTO = "fully_auto"      # 完全自动
    SEMI_AUTO = "semi_auto"        # 半自动（需审批）
    MANUAL_ONLY = "manual_only"    # 仅手动

# 配置（.env）
DECISION_TOPIC_SELECTION=semi_auto      # 话题选择需审批
DECISION_CONTENT_GENERATION=semi_auto   # 内容生成需审批
DECISION_COVER_GENERATION=fully_auto    # 封面生成自动
DECISION_PUBLISH=manual_only            # 发布必须手动
DECISION_STRATEGY_ADJUSTMENT=semi_auto  # 策略调整需审批
```

### 风险评分与自动降级

```python
# 自动评估话题风险
risk_score = risk_assessment.assess_topic_risk("某话题")

if risk_score > 0.7:
    # 高风险 → 强制人工审核
    decision_level = DecisionLevel.MANUAL_ONLY
elif risk_score > 0.3:
    # 中风险 → 半自动
    decision_level = DecisionLevel.SEMI_AUTO
else:
    # 低风险 → 完全自动
    decision_level = DecisionLevel.FULLY_AUTO
```

### 审计日志与回滚

所有决策都会记录审计日志，支持一键回滚：

```python
# 回滚错误决策
await audit_log.rollback_decision(decision_id="dec_123")
```
