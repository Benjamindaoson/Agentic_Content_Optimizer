```python
class Experiment(Base):
```

**统计分析**:
```python
@dataclass
class ExperimentResult:
    # 对照组
    control_mean: float
    control_std: float
```

```python
# 4. 发布后记录指标
platform.record_metric(
```

### 3. 数据质量服务：持续审计与自动修复

**问题**: 生产系统会出现数据腐烂（缺封面/缺指标/重复/错配）

**解决方案**:

#### 数据质量服务
**文件**: `backend/app/quality/data_quality_service.py` (800+ 行)

**核心功能**:
- 完整性审计
- 一致性检查
- 有效性检查
- 重复检查
- 自动修复
- 质量评分
- 问题追踪

**关键类**:
```python
class DataQualityService:
    async def run_audit(self, scope='all') -> DataQualityReport:
        """运行数据质量审计"""
        # 1. 检查完整性（缺失指标/封面/分析）
        # 2. 检查一致性（时间错配）
        # 3. 检查有效性（空标题/负数指标/逻辑错误）
        # 4. 检查重复
        # 5. 自动修复
        # 6. 计算质量分数
        # 7. 告警

    async def _check_completeness(self, notes) -> List[DataIssue]:
        """检查完整性"""
        # 检查每个笔记是否有 metrics/cover/analysis

    async def _check_consistency(self, notes) -> List[DataIssue]:
        """检查一致性"""
        # 检查时间一致性（采集时间 vs 发布时间）

    async def _check_validity(self, notes) -> List[DataIssue]:
        """检查有效性"""
        # 检查空标题/空正文/负数指标/逻辑错误

    async def _auto_fix_issues(self, issues) -> int:
        """自动修复"""
        # 缺封面 → 触发重新下载
        # 缺分析 → 触发重新分析
```

**数据模型**:
```python
class DataQualityReport(Base):
    report_id: str  # 主键
    audit_time: datetime  # 审计时间
    overall_score: float  # 总体质量分数
    completeness_score: float  # 完整性分数
    consistency_score: float  # 一致性分数
    validity_score: float  # 有效性分数
    total_notes: int  # 总笔记数
    issues_found: int  # 发现问题数
    issues_fixed: int  # 已修复问题数
    issues_by_type: JSON  # 按类型统计
    issues_by_severity: JSON  # 按严重程度统计

class DataIssue(Base):
    issue_id: str  # 主键
    report_id: str  # 报告ID
    issue_type: DataIssueType  # 问题类型
    severity: IssueSeverity  # 严重程度
    note_id: str  # 笔记ID
    is_fixed: bool  # 是否已修复
    fix_method: str  # 修复方法
```

**质量评分**:
```python
overall_score = (
    0.4 * completeness_rate +  # 完整性权重 40%
    0.3 * (1 - duplicate_rate) +  # 去重权重 30%
    0.2 * (1 - mismatch_rate) +  # 一致性权重 20%
    0.1 * (1 - invalid_rate)  # 有效性权重 10%
)
```

**自动修复策略**:
- 缺封面 → 发送 Celery 任务重新下载
- 缺分析 → 发送 Celery 任务重新分析
- 其他问题 → 标记待人工处理

**效果**:
- ✅ 系统长期跑不会越跑越脏
- ✅ RL 训练不会被坏数据带偏
- ✅ 数据质量分数 > 0.9
