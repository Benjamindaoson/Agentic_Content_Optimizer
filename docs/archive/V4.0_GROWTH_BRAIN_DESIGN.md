## 🎯 核心理念

**从"内容引擎"进化为"增长大脑"**

v4.0 的本质是让系统从"帮人做内容"升级为"替人做决策" - 系统知道做什么、何时做、如何做，并且能解释为什么这样做有效。

## 🏗️ 四大核心升级

### 1. 自动化账号运营 (Auto-Account Manager) ✅ 已实现

**文件**: `backend/app/growth_brain/auto_account_manager.py` (1,000+ 行)

**核心能力**:
- 自动选题（话题发现）
- 智能排程（最优发布时间）
- 内容编排（自动生成）
- 效果监控（实时追踪）
- 策略调整（自动优化）

**工作流**:
```
每日 6:00 AM
  ↓
1. 扫描热点话题（小红书/微博/抖音）
  ↓
2. 结合账号人设 + 历史数据 → 选出 3-5 个话题
  ↓
3. 为每个话题生成 2-3 个变体（不同 Hook/角度）
  ↓
4. 预测最优发布时间（基于历史互动数据）
  ↓
5. 自动排程 → 自动生成 → 自动发布
  ↓
6. 实时监控前 1 小时数据
  ↓
7. 如果表现差 → 触发补救策略（修改标题/换封面）
```

**关键技术**:
- 话题发现: LDA + BERT 聚类
- 时间优化: 时序预测模型（LSTM）
- 人设适配: 关键词匹配 + 语义相似度

**数据模型**:
- `DiscoveredTopic`: 发现的话题
- `ContentSchedule`: 内容排程
- `DailyPlan`: 每日计划

### 2. 多模态封面引擎 (Multimodal Cover Engine) ✅ 已实现

**文件**: `backend/app/growth_brain/multimodal_cover_engine.py` (900+ 行)

**核心能力**:
- 封面自动生成（SD/MJ/DALL·E）
- 点击率预测
- A/B 测试
- 风格优化

**工作流**:
```
生成内容
  ↓
1. 根据标题 + 正文 → 生成 5 张候选封面
  ↓
2. 提取特征（色彩/构图/人脸/文字）
  ↓
3. 用 CTR 预测模型预筛选 → 留下 Top 3
  ↓
4. 小流量发布（各 10% 流量）
  ↓
5. 1 小时后统计点击率
  ↓
6. 选胜出封面 → 全量推送
```

**关键技术**:
- 生成器: Stable Diffusion XL / MidJourney / DALL·E 3
- 特征提取: OpenCV + 色彩分析
- CTR 预测: LightGBM（特征 → 点击率）
- A/B 测试: 贝叶斯 Thompson Sampling

**数据模型**:
- `GeneratedCover`: 生成的封面
- `CoverABTest`: A/B 测试
- `CoverFeatures`: 封面特征

### 3. 多平台内容引擎 (Multi-Platform Engine) ⏳ 待实现

**文件**: `backend/app/growth_brain/multi_platform_engine.py`

**核心能力**:
- 统一内容格式（UCF）
- 平台适配器（XHS/Douyin/Bilibili）
- 跨平台发布
- 跨平台效果对比

**统一内容格式 (UCF)**:
```python
@dataclass
class UnifiedContent:
    """统一内容格式"""

    # 核心内容
    title: str
    body: str
    hook: str
    call_to_action: str

    # 多模态资源
    cover_image: Image
    video: Optional[Video]
    audio: Optional[Audio]

    # 元数据
    topic: str
    tags: List[str]
    target_audience: AudienceProfile

    # 平台适配
    platform_configs: Dict[Platform, PlatformConfig]
```

**平台适配器**:
```python
class XHSAdapter(PlatformAdapter):
    """小红书适配器"""
    - 标题: 保留 emoji
    - 正文: 分段 + 话题标签
    - 封面: 3:4 比例

class DouyinAdapter(PlatformAdapter):
    """抖音适配器"""
    - 标题: 简短（< 30 字）
    - 视频: 9:16 竖屏
    - 字幕: 自动生成

class BilibiliAdapter(PlatformAdapter):
    """B站适配器"""
    - 标题: 详细（可长）
    - 视频: 16:9 横屏
    - 分 P: 支持多集
```

**跨平台发布流程**:
```
生成 UnifiedContent
  ↓
1. 选择目标平台（小红书 + 抖音 + B站）
  ↓
2. 并行适配
  ↓
3. 各平台独立 A/B 测试
  ↓
4. 跨平台效果对比
  ↓
5. 学习"哪个平台适合哪类内容"
```

### 4. 因果推断引擎 (Causal Inference Engine) ⏳ 待实现

**文件**: `backend/app/growth_brain/causal_inference_engine.py`

**核心能力**:
- 因果图建模
- 反事实推理
- 策略优化
- 混淆消除

**从"预测"到"因果"**:

**当前 v3.2**:
```python
# 预测模型
viral_score = f(features)  # 黑盒
```

**v4.0 因果模型**:
```python
# 因果图
Hook类型 → 观看率
封面色彩 → 点击率
发布时间 → 完播率
正文长度 → 收藏率

# 因果推断
from dowhy import CausalModel

model = CausalModel(
    data=df,
    treatment='hook_type',
    outcome='engagement_rate',
    common_causes=['topic', 'author_followers']
)

# 估计因果效应
causal_effect = model.estimate_effect()
# → "疑问句 Hook 比陈述句 Hook 提升互动率 15%（因果效应）"
```

**应用场景**:
1. **策略优化**: "改变 X 会导致 Y 提升多少？"
2. **反事实推理**: "如果当时用了另一个 Hook，会怎样？"
3. **混淆消除**: "是 Hook 导致爆款，还是话题本身就热？"

**关键技术**:
- 因果图: DAG（有向无环图）
- 因果推断: DoWhy / EconML
- 反事实: Counterfactual Reasoning
- 混淆控制: Propensity Score Matching
