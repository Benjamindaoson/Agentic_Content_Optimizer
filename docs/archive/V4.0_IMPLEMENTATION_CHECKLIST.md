## 🚀 部署步骤

### 1. 数据库迁移
```bash
cd backend
alembic upgrade v4_0_growth_brain
```

### 2. 配置环境变量
```bash
# 在 .env 文件中添加
STABLE_DIFFUSION_API_KEY=your_key
OPENAI_API_KEY=your_key
MIDJOURNEY_API_KEY=your_key
XHS_ACCOUNT_COOKIE=your_cookie
DOUYIN_ACCOUNT_COOKIE=your_cookie
BILIBILI_ACCOUNT_COOKIE=your_cookie
```

### 3. 启动服务
```bash
# FastAPI
uvicorn app.api:app --reload --port 8000

# Celery Worker
celery -A app.tasks.celery_config worker --loglevel=info

# Celery Beat
celery -A app.tasks.celery_config beat --loglevel=info
```

### 4. 验证部署
```bash
# 健康检查
curl http://localhost:8000/api/v4/health

# 应该返回
{
  "version": "4.0.0",
  "status": "healthy",
  "modules": {
    "auto_account_manager": "ready",
    "multimodal_cover_engine": "ready",
    "multi_platform_engine": "ready",
    "causal_inference_engine": "ready"
  }
}
```

### v3.2 → v4.0 的跃迁

| 维度 | v3.2 | v4.0 | 提升 |

### 系统本质变化

**v3.2**: "内容引擎" - 帮人做内容

系统不再是工具，而是一个**自主运营的增长大脑**：
- 知道做什么（话题选择）
- 知道何时做（智能排程）
