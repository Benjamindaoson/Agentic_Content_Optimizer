### 4. 消息队列：Celery + Redis ✅

**选择理由**：
- ✅ Python 生态最好
- ✅ 功能完整（定时任务/重试/监控）
- ✅ 易于使用

**配置**：
```python
# celery_config.py
from celery import Celery
from celery.schedules import crontab

celery_app = Celery(
    "growth_brain",
    broker="redis://localhost:6379/0",
    backend="redis://localhost:6379/1"
)

# 定时任务
celery_app.conf.beat_schedule = {
    'discover-topics-daily': {
        'task': 'app.tasks.discover_topics',
        'schedule': crontab(hour=6, minute=0),
    },
}

# 任务定义
@celery_app.task(bind=True, max_retries=3)
def discover_topics_task(self):
    try:
        topics = discover_topics()
        return topics
    except Exception as e:
        self.retry(exc=e, countdown=60)
```

**运行**：
```bash
# Worker
celery -A app.celery_config worker --loglevel=info --concurrency=4

# Beat（定时任务）
celery -A app.celery_config beat --loglevel=info

# Flower（监控）
celery -A app.celery_config flower --port=5555
```

**选择理由**：

- ✅ 性能优秀

**安装**：


**API 调用**：
```python
import aiohttp
import json

class ComfyUIClient:
    """ComfyUI API 客户端"""

    def __init__(self, base_url: str = "http://localhost:8188"):
        self.base_url = base_url

    async def generate(self, prompt: str) -> bytes:
        """生成图片"""
        # 1. 构建工作流
        workflow = {
            "3": {
                "class_type": "KSampler",
                "inputs": {
                    "seed": random.randint(0, 2**32),
                    "steps": 1,  # SDXL Turbo 只需 1 步
                    "cfg": 1.0,
                    "sampler_name": "euler",
                    "scheduler": "simple",
                    "denoise": 1.0,
                    "model": ["4", 0],
                    "positive": ["6", 0],
                    "negative": ["7", 0],
                    "latent_image": ["5", 0]
                }
            },
            "6": {
                "class_type": "CLIPTextEncode",
                "inputs": {
                    "text": prompt,
                    "clip": ["4", 1]
                }
            },
            # ... 更多节点
        }

        # 2. 提交任务
        async with aiohttp.ClientSession() as session:
            async with session.post(
                f"{self.base_url}/prompt",
                json={"prompt": workflow}
            ) as resp:
                result = await resp.json()
                prompt_id = result["prompt_id"]

            # 3. 轮询结果
            while True:
                async with session.get(
                    f"{self.base_url}/history/{prompt_id}"
                ) as resp:
                    history = await resp.json()
                    if prompt_id in history:
                        break
                await asyncio.sleep(0.5)

            # 4. 下载图片
            output = history[prompt_id]["outputs"]["9"]["images"][0]
            filename = output["filename"]

            async with session.get(
                f"{self.base_url}/view?filename={filename}"
            ) as resp:
                image_bytes = await resp.read()

        return image_bytes

# 使用
client = ComfyUIClient()
image = await client.generate("a beautiful landscape")
```

**性能**：
- SDXL Turbo: ~0.8s/张 (RTX 4090)
- SDXL: ~3s/张 (RTX 4090)

**替代方案**：
- **Fooocus**：更简单，但功能较少
- **AUTOMATIC1111**：经典，但性能较低
- **InvokeAI**：界面友好

### 9. 爬虫：Playwright ✅

**选择理由**：

- ✅ 反爬能力强

**安装**：


**使用**：
```python
from playwright.async_api import async_playwright

async def crawl_xhs(keyword: str) -> List[Dict]:
    """爬取小红书"""
    async with async_playwright() as p:
        # 1. 启动浏览器
        browser = await p.chromium.launch(headless=True)
        context = await browser.new_context(
            user_agent="Mozilla/5.0...",
            viewport={"width": 1920, "height": 1080}
        )
        page = await context.new_page()

        # 2. 访问页面
        await page.goto(f"https://www.xiaohongshu.com/search_result?keyword={keyword}")

        # 3. 等待加载
        await page.wait_for_selector(".note-item")

        # 4. 提取数据
        notes = await page.evaluate("""
            () => {
                return Array.from(document.querySelectorAll('.note-item')).map(item => ({
                    title: item.querySelector('.title')?.textContent,
                    likes: item.querySelector('.likes')?.textContent,
                    url: item.querySelector('a')?.href
                }));
            }
        """)

        await browser.close()
        return notes
```

**替代方案**：
- **Scrapy**：经典框架，但同步
- **Selenium**：老旧，性能差

```python
from prometheus_client import Counter, Histogram, generate_latest
from fastapi import Response

# 定义指标
request_count = Counter('api_requests_total', 'Total API requests', ['method', 'endpoint'])
request_duration = Histogram('api_request_duration_seconds', 'API request duration')

@app.middleware("http")
async def metrics_middleware(request: Request, call_next):
    with request_duration.time():
        response = await call_next(request)
    request_count.labels(method=request.method, endpoint=request.url.path).inc()
    return response

@app.get("/metrics")
async def metrics():
    return Response(content=generate_latest(), media_type="text/plain")
```
