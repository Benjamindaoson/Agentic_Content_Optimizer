### 2. RAG 检索和评估
```python

from app.rag.evaluation.rag_evaluator import RAGEvaluator

    query="AI 写作",
    limit=10,
    use_query_expansion=True,
    use_reranking=True
)

evaluator = RAGEvaluator()
metrics = await evaluator.evaluate_retrieval(
    query="AI 写作",
    retrieved_docs=results,
    relevant_doc_ids=[...]
)
```

```python

    key_data={"topic": "AI 写作", "platform": "xiaohongshu"}
)

    result = await generate_content(...)
    cache_manager.generation_cache.set(
        key_data={"topic": "AI 写作", "platform": "xiaohongshu"},
        value=result,
        ttl=7200
    )
```
